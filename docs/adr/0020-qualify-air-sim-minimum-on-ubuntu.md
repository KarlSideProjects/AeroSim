# Qualify the AirSim-class minimum on Ubuntu x86_64

The first complete AirSim-class release will be qualified on Ubuntu x86_64, including PX4 SITL, RPC, the Baseline Sensor Suite, Dataset Recording, the reference environment, and visual gates. Windows and Android may retain Player Mode release lanes, but Lab Mode parity on those platforms does not block the first qualification; requiring simultaneous full parity would delay the only platform needed to prove the product contract.
