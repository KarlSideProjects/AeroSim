# Use Kenney City Kit Industrial as the reference asset set

The Industrial Test Range will use Kenney City Kit (Industrial), licensed CC0, as its primary visual asset set and supplement gaps only with Godot primitives or project-created assets. The source archive, license, version, and hash will be recorded and the approved assets checked in; Unity and Unreal scene conversion will not be a production dependency because it would add unverifiable engine-specific materials, UI, logic, and licensing risk.
