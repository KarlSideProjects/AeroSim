# Use a project-created reference vehicle visual

Both Vehicle Instances will use one visual-only quadrotor asset consistent with the Kenney environment and will differ by stable accent color. The current non-commercial prototype may use the checked-in Free3D Personal Use asset recorded in `assets/third_party/free3d_drone/asset_notes.md`; a commercial or redistributable release must replace it with a project-created or otherwise redistributable asset. Visual nodes remain separate from physics, collision, and sensor mounts so appearance changes cannot alter simulation frames or authority.
