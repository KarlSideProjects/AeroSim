# Make AeroSim a simulation platform with a game-like default experience

AeroSim will be designed as a multirotor-only simulation platform first, with Player Mode as its default entry and Lab Mode exposing the same simulated world to software. This rejects a game-only scope, which cannot reach the AirSim-class minimum, and a lab-only scope, which would abandon the requested approachable Godot experience. Cars and road-vehicle simulation are excluded because they would add a second vehicle and environment domain without improving the drone product.
