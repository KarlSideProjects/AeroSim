# AeroSim 開發者總覽

AeroSim 是一個讓人與軟體共用同一模擬世界的 **Simulation Platform**。Player Mode
是人操作無人機的入口；Lab Mode 是程式控制、觀測 Vehicle Instance 與感測器的入口。
這兩種模式共享模擬狀態，而不是兩個產品。

本頁會隨能力與術語導覽擴充；所有產品主張以 PRD 與 Product Capabilities 為準。
