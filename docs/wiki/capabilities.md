# AeroSim 能力與狀態

能力狀態沿用 Product Capabilities：**Available** 表示目前分支有直接測試證據，
**Foundation** 表示部分行為已存在，**Confirmed target** 表示已確認但尚未完成的產品合約。
本頁不會把目標或 issue 討論表述成已可用功能。
