## 搜尋與標記規則

每頁的 `title` 使用繁體中文；`aliases` 是非空清單，至少保留一個穩定的英文搜尋別名，
需要時可加入繁體中文別名。每個頁面都必須附上可追溯的 `sources` 與 ISO 日期格式的
`last_verified`；完整規則與狀態詞彙見[維護與來源規則](maintenance.md)。
