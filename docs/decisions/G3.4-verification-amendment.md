## 原文與問題

PRD G3.4 原文：「固定 seed、Welch 法（段長 2¹⁴、50% overlap、Hann 窗）估 PSD，0.1–10 rad/s 各 bin 與理論譜偏差 ≤ 10%（95% 信賴區間內）」。

問題：**單一有限長度隨機實現**的 Welch PSD 估計每個 bin 有內生統計變異，「每 bin ≤ 10%」對單一實現在統計上近乎不可判定——通過與否取決於運氣而非實作正確性，違反 Gate 應「可重測、可判定」的原則。原文括號「（95% 信賴區間內）」正暗示判定應在統計信賴框架內進行。

## 修正後驗收（兩層，取代原單層）

1. **解析轉移函數逐 bin ≤ 10%**：直接以實作之 Dryden 成形濾波器的解析頻率響應對照 MIL-F-8785C 理論譜，逐 bin ≤ 10%——確定性判定、無估計噪音可躲，**嚴格度高於原文**。
2. **Welch 隨機實現 95% CI 煙霧驗證**：固定 seed 之實現，其 Welch 估計落於理論譜之 95% 信賴區間。
3. 不變項：輕/中/重三檔全過；同 seed 重跑 bitwise 一致。

## 判定性質

本修正屬**驗證方法修正**，門檻數值（10%、頻段、三檔、決定性）未動，不構成 PRD 4.0 所禁止之門檻下修。
