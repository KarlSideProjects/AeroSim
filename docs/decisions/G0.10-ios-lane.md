# G0.10 — iOS Lane Go/No-Go 決策

| 欄位 | 內容 |
|---|---|
| 決策 | **Go — Ad Hoc 路線** |
| 決策日期 | 2026-07-08 |
| 決策人（簽核） | Karl（維護者，經 triage 會話決策） |
| 對應 issue | #19（G0.10）、#55（iOS Lane 實作追蹤） |

## 決策內容

iOS Lane 由「凍結」轉為 **Go**，採 **Ad Hoc 發行路線**：

- 目標規模：**約 10 台私人使用裝置**，遠低於 Ad Hoc 100 台/年上限，容量無虞。
- 不採 TestFlight：無需承擔 Apple 審查風險與 build 90 天過期的維運節奏；私人小規模用 Ad Hoc 即足。
- Enterprise Program 依 PRD 1.4 確認不可行（僅限自家員工）。

## 已知成本與義務（接受）

- Apple Developer Program 年費（USD 99/年）。
- UDID 收集：每台目標裝置需註冊 UDID 後重簽 provisioning profile。
- **描述檔每年過期**：需建立年度重簽與重發 SOP（納入 #55 與 Phase 6 交付流程）。
- 工程成本：G0.6b iOS build smoke、SDL3 MFi 控制器路徑（G5.3）、iPhone 13（A15）基準機 QA（G4.2）、Metal/Mobile Renderer 驗證。

## 剛性約束重申

- **C-1**：iOS 禁止 spawn subprocess；Tier 2 / Tier 3 永久禁止進入 iOS。
- iOS Lane 為獨立 Lane：其 Gate 未過僅凍結 iOS，不阻擋其他 Lane。

## 後續動作

1. `lane:ios` 各 Gate 解凍：G0.6b（iOS smoke）、G0.9、G4.2、G5.3、G5.4、G6.4、G6.5。
2. 開立 #55 追蹤 iOS Lane 打通（build smoke → MFi/VirtualJoystick → Ad Hoc 佈署 SOP）。
3. PRD 正本 1.4 節之 iOS 列「凍結，Phase 0 後決策」自本決策起以本文件為準；下次 PRD 版本更新時收錄。

## 目前環境的執行狀態

本決策保留 iOS Lane 的 Ad Hoc 路線選擇，但在目前沒有 iOS 實機與 macOS/Xcode runner 的環境下，所有 Ad Hoc 部署與裝置驗收均暫為 **N/A，非 pass**；實際 iOS build smoke 為 **not verified**。目前可執行範圍以 [本機 Ubuntu 基準與行動 build-only 車道](2026-07-10-local-ubuntu-build-only-lanes.md) 為準。
