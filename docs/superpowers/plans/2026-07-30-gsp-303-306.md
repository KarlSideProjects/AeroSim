# GSP #303–#306 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the wind-command, PX4-observability, portrait GSP, and qualification slices from #303–#306 without implementing #302 geometry work.

**Architecture:** The authoritative simulation path lands first: a bounded GSP wind command commits at a physics tick and replays deterministically; PX4 telemetry then extends only the validated MAVLink boundary. The WebUI consumes those source-labelled values and preserves `Nominal geometry` until the separately-owned #302 asset exists. Qualification is the final gate and may close an issue only after an independent computer-use validation plus the required CI checks pass.

**Tech Stack:** Godot 4.7 GDScript, C++17 GDExtension, local file-loaded GSP WebUI, vendored Three.js/Canvas, PX4 SITL/MAVLink, native and headless tests.

## Global Constraints

- Implement #303, #304, #305, and #306 only; do not implement or close #302.
- Keep all hardware values in the active Hardware configuration and JSON presets; no airframe constants in runtime/view code.
- GSP remains a loopback-authenticated, offline, local `file://` WebUI; do not add a frontend framework, network fetch, or second runtime.
- Wind input is meteorological “from” bearing; its resolved NED/toward representation, applied tick, ACK, and replay event must agree.
- PX4 High Fidelity is exclusive and fails closed; expose only validated MAVLink fields, and never relabel AeroSim/local values as PX4-reported data.
- Classify visible values as Commanded, Ground truth, Estimated, or Measured. Missing values remain unavailable, never fabricated or zero-filled.
- `即時狀態` must be zero-scroll at CSS content sizes 480×854, 560×996, and 640×1138; `工程設定` may scroll.
- #305 may show only explicit `Nominal geometry` until #302 provides qualified real geometry. Do not close #305 or dependent #306 while #302 remains open.
- Before closing any issue, a fresh validation agent must run the required CI checks and use computer-use against the actual UI; it independently decides whether evidence supports closure.
